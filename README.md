# Letlotlo Mogatusi — Virtual CV

A single-page virtual CV built with plain HTML and CSS, styled as a football-inspired "player card" layout.

## Live Demo

View it on GitHub Pages: https://lmogatusi.github.io/Virtual-CV-/

## Structure

```
.
├── index.html   # Page content
├── style.css    # Styling
└── README.md
```

## Sections

- Hero / player card intro
- About
- Key Skills
- Academic Projects
- Education & Certifications
- Extracurricular Activities
- Contact

## Tech

- HTML5
- CSS3 (custom properties, grid, animations)
- Vanilla JavaScript (scroll reveal + stat bar animation)
